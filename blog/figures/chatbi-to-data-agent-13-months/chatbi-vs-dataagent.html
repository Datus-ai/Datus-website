ChatBI and DataAgent: two paradigms

ChatBI (the GPT-4o era)

User asks a question
▾
Retrieve knowledge base / SQL fragments
▾
Splice into one large prompt
▾
Model generates SQL in one shot
▾
Return the result (right or wrong, who knows)
One question, one answer · knowledge configured by hand · nobody reviews the misses

DataAgent (the multi-model era)

User gives a task
▾
Plan: break it into multiple analysis steps
▾
Call tools: metrics / templates / SQL
▾
Hook validation + permission injection
▾
Drill down · compare · attribute · write up
Multi-step execution · domain context + tools + boundaries · feedback flows back
