A practical architecture has five layers

1. Core semantic modeldatasets, fields, keys, relationships
2. Governed metricsmeasures, grain, filters, time semantics
3. Ontology layerEntityTypes, ValueTypes, roles, domains
4. Entity / query planequery_objects, select, ontology_sql
5. Agent functionstyped business tools and workflows

Metrics and ontology sit side by side on one semantic model; the entity plane and typed functions are what the agent actually calls.
